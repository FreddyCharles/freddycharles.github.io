Methodology

COST FUNCTION

Mean Squared Error (MSE)

Quantifying Variance

  • Measures model accuracy by calculating the average squared distance between data vectors and the trendline.
  • Defines the objective landscape to minimize: J(m, c) = (1/2N) Σ ( (m x_i + c) - y_i )².
ITERATIVE

Gradient Descent (GD)

Step-by-Step Optimization

  • Calculates parameter adjustments by tracking local loss gradients relative to the line slope (m) and intercept (c).
  • Updates system weights in increments set by the learning rate parameter to guide the function toward global minima.
CLOSED-FORM

Ordinary Least Squares (OLS)

Analytical Resolution

  • Resolves optimal trend parameters directly using covariance formulas rather than successive mathematical steps.
  • Highly performant for low-dimensional coordinate spaces, though computationally demanding as matrix sizing grows.
