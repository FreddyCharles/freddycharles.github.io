THE OBJECTIVE

Linear regression aims to map the relationships within a set of data by fitting a straight line to the collected data points.

01.1 / COST FUNCTION

Mean Squared Error

Mathematical Formulation
  • Quantifies prediction error by calculating the average squared variance between coordinates and the trendline.
  • The mathematical definition: J(m, c) = (1/2N) Σ ( (m x_i + c) - y_i )².
  • Lower loss values represent heightened line accuracy.

GRADIENT DESCENT

Iterative Optimization

Step-by-Step Convergence
  • Takes steps proportional to the negative gradient of the loss function to reach local or global minima.
  • Allows scaling when processing billions of multi-dimensional parameters where matrix inversions are impossible.
CLOSED FORM

Ordinary Least Squares

Direct Analytical Resolution
  • Calculates optimal parameters instantaneously utilizing traditional closed-form covariance formulations.
  • Highly performant for low-dimensional vectors but scales poorly in complexity during extensive matrix transitions.
